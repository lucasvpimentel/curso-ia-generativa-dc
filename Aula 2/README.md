# Aula 2: Engenharia de Prompt (Prompt Engineering)

Bem-vindo à Aula 2! Este módulo é focado em **Engenharia de Prompt**, uma disciplina crucial para extrair o máximo de desempenho de Modelos de Linguagem de Grande Escala (LLMs).

Este material foi desenhado para uma aula abrangente de várias horas, indo desde a formatação básica de instruções até frameworks avançados de raciocínio.

📚 **Referência Principal:** [Prompt Engineering Guide](https://www.promptingguide.ai/pt)

## Estrutura do Módulo

O material teórico está dividido em quatro partes sequenciais:

1. **[Fundamentos e Parâmetros](./teoria/01_fundamentos_e_parametros.md):** 
   - Estruturação de instruções
   - Uso de delimitadores
   - Controle de Temperatura e Top-P
   - Entendendo e otimizando Tokens.

2. **[Técnicas Estruturais básicas](./teoria/02_tecnicas_estruturais.md):**
   - Role Prompting (Atribuição de Papel)
   - Zero-shot Prompting
   - One-shot e Few-shot Prompting.

3. **[Técnicas de Raciocínio Avançado](./teoria/03_raciocinio_avancado.md):**
   - Chain of Thought (CoT)
   - Self-Consistency
   - Tree of Thoughts (ToT)
   - ReAct (Reasoning and Acting)
   - Prompt Chaining.

4. **[Ferramentas e Frameworks](./teoria/04_ferramentas_e_frameworks.md):**
   - LangChain
   - PromptLayer
   - OpenPrompt

## Como Estudar

1. Leia os documentos na pasta `teoria/` em ordem cronológica.
2. Teste os prompts apresentados em interfaces como ChatGPT, Claude ou via API (caso já tenha sua chave configurada).
3. Observe como pequenas mudanças de temperatura ou a adição de um único exemplo (few-shot) podem alterar completamente a saída da IA.
