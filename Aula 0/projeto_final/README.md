## O Desafio

Neste projeto final, você vai construir um **Gerador de Agentes de IA**. O script será interativo e permitirá que você defina a personalidade, a função e as configurações de um assistente de IA, gerando no final um pacote JSON pronto para ser usado em uma integração real.

---

## O que o script deve fazer?

1.  Pedir o nome do agente e sua especialidade.
2.  Permitir a escolha de um "Tom de Voz" (Formal ou Criativo).
3.  Montar um **System Prompt** automaticamente usando as informações coletadas.
4.  Organizar tudo em um dicionário estruturado.
5.  Exibir o resultado final em formato JSON formatado.

---

### Como rodar?
Basta executar o arquivo `gerador_agente.py` e seguir as instruções na tela!
