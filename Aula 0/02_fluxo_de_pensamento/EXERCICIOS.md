# 🏋️ Lista de Exercícios: O Fluxo de Pensamento (Módulo 2)

## 🧪 Exercício 1: Validador de Prompt
Crie um código que peça um prompt ao usuário (`input`).
- Se o prompt for "vazio" (tamanho 0), diga "Prompt inválido".
- Se tiver menos de 10 caracteres, diga "Prompt muito curto".
- Caso contrário, diga "Prompt enviado!".

## 🧪 Exercício 2: Repetidor de Respostas
Use um loop `for` para imprimir a frase `"Gerando resposta IA..."` exatamente 5 vezes.
