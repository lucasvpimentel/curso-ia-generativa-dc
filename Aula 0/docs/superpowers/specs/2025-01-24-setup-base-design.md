# Design Doc: Estrutura Base e Módulo 0 (Setup)

## Objetivo
Criar a base do curso "Python - Do Zero ao Prompt", estabelecendo o tom acolhedor e a temática de Alquimia/Culinária para atrair e manter iniciantes.

## Tom e Voz
- **Acolhedor:** Foco em pessoas em transição de carreira.
- **Didático:** Sem jargão puro; tudo é explicado com analogias.
- **Místico/Alquímico:** O código é uma ferramenta de transformação (Python como o elemento base para criar IA).

## Estrutura de Arquivos
- `/README.md`: O Mapa da Jornada (Sumário e Boas-vindas).
- `/00_setup/README.md`: Preparando o Laboratório (Instalação e Terminal).
- `/00_setup/script.py`: O Primeiro Feitiço (Olá Mundo).
- `/00_setup/exercises.py`: Praticando a Magia (Primeiro Exercício).

## Conteúdo Detalhado

### README.md (Raiz)
- Mensagem de boas-vindas: "Bem-vindo à Jornada do Alquimista de Dados".
- Analogia: Transformar linhas de código em inteligência.
- Sumário dos módulos (0 a 5 + Projeto Final).
- Instruções de navegação.

### 00_setup/README.md
- Instruções claras para Windows, Mac e Linux.
- Uso do Terminal: "Onde os comandos ganham vida".
- Comandos básicos: `python --version` e `python script.py`.

### 00_setup/script.py
- Código simples: `print("Olá, Mundo!")`.
- Comentários ricos explicando cada parte (função, parênteses, aspas).

### 00_setup/exercises.py
- Desafio prático para personalização da mensagem de saída.

## Critérios de Sucesso
- Arquivos criados com conteúdo condizente com o tom solicitado.
- Scripts Python válidos e funcionais.
- READMEs fáceis de seguir para leigos totais.
